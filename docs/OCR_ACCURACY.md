## Limitations

- The test images are single printed lines in a standard font. Real scans (handwriting, multi-column pages, tables, stamps, heavy skew or low resolution) will score lower; add such samples to the test set when real, non-confidential documents are available.
- The degradations used for "low" images did not reduce Florence-2's accuracy much, so the low-quality set is easier than real poor scans and should be made harder.
- The first document includes model loading time; later documents show the steady-state speed.
